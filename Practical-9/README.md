# Practical 9 - Secure User Registration
StudentHub (ITUE203 WDF, 25CE052)

## Run
1. Copy this folder into `www` (WAMP) or `htdocs` (XAMPP), e.g. `www/Practical-9`.
2. Start Apache and MySQL, then import `sql/studenthub.sql` once in phpMyAdmin (creates database `studenthub`).
3. Open `http://localhost/Practical-9/`
