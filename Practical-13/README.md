# Practical 13 - PHP JSON API and AJAX/Fetch CRUD
StudentHub (ITUE203 WDF, 25CE052)

## Run
1. Copy this folder into `www` (WAMP) or `htdocs` (XAMPP), e.g. `www/Practical-13`.
2. Start Apache and MySQL, then import `sql/studenthub.sql` once in phpMyAdmin (creates database `studenthub`).
3. Open `http://localhost/Practical-13/`

## Demo accounts
- Admin: admin@studenthub.local / Admin@123
- Student: student@studenthub.local / Student@123

JSON endpoint: `http://localhost/Practical-13/api/students.php` (open it while logged in as admin).
