About StudentHub

StudentHub is a student portal designed to help students access important academic information in one place.

Students can view their timetable, check results, access notices, and manage academic activities easily.

The website uses CSS Flexbox and CSS Grid to create a responsive layout that works on desktops, tablets, and mobiles.
